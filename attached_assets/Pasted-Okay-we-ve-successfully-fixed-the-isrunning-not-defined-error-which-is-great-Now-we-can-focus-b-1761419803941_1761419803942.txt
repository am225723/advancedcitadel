          <EffectComposer>
            <Bloom
              intensity={
                isRunning
                  ? (phase === 'hold' || phase === 'holdAfter'

              mipmapBlur
              radius={0.3} // Smaller bloom radius for a tighter glow
            />
            <Vignette
              eskil={false}
              offset={0.12}
              darkness={
                isRunning && (phase === 'hold' || phase === 'holdAfter')
                  ? 1.4
                  : 1.2
              }
            />
            <ChromaticAberration
              blendFunction={BlendFunction.NORMAL}
              offset={[0.0004, 0.0004]}
            />
          </EffectComposer>

Key settings to re-verify:
 * luminanceThreshold={0.9}: This is the most crucial one. It tells the bloom to ignore anything that isn't almost pure white.
 * intensity values: All the intensity values in the conditional statement should be much lower, ranging from 0.05 to 0.2.
 * radius={0.3}: This keeps the bloom tight around the brightest parts.
If you have already applied these exact settings and are still seeing the same blown-out image, then the problem might be originating from within the flame shader itself, making the finalColor and alpha values too high, even before bloom is applied.
